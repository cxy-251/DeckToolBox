## 下载

| 系统 | 文件 | 用法 |
| --- | --- | --- |
| Linux / Steam Deck (x86_64) | `*-linux-x86_64.AppImage` | `chmod +x` 后直接运行，不需要安装 |
| Linux (x64 / arm64) | `*-linux-x64.tar.gz`、`*-linux-arm64.tar.gz` | 解压后运行 `./install.sh`，安装到 `~/Applications/DeckToolBox` 并加入应用菜单；`./install.sh --uninstall` 卸载 |
| Windows (x64) | `*-win-x64-setup.exe` | 安装程序，按用户安装，不需要管理员权限 |
| Windows (x64 / arm64) | `*-portable.zip` | 解压即用 |
| macOS (Apple Silicon / Intel) | `*-osx-arm64.dmg`、`*-osx-x64.dmg` | 把 DeckToolBox 拖入「应用程序」。应用未经 Apple 公证，首次打开需在「系统设置 → 隐私与安全性」中点击「仍要打开」 |

所有安装包都自带 .NET 运行时，无需另外安装。校验值见 `SHA256SUMS.txt`。
